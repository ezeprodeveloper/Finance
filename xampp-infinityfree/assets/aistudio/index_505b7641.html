HELP CENTER

Frequently asked questions

Is this website connected to my Android app?

This package provides the website interface and GitHub Pages deployment. A shared backend still needs to be configured before Android and web accounts, balances and transactions synchronize.

Can I deposit or withdraw money now?

Not from this static website package. Live money movement requires a verified payment provider integration, server-side validation, security testing and the required business approvals.

How do I get the Android app?

Open the repository's Actions tab, select a successful Android CI run and download the APK artifact.
